  4. *Доказовий пласт (Evidence Layer):* протоколи випробувань HIL, звіти статичного аналізу коду, матриці покриття та траси верифікації.

#### [ID: CH10-S18-02] Аналітична формула точки беззбитковості апаратного прискорення ($`N^*`$)

#### [ID: CH10-S24-02] Незміщений оцінювач Горвіца — Томпсона середньої щільності знань у страті
- **Розташування в книзі:** Розділ 24, підрозділ 24.1, рядки 1341–1350.
- **Наукова форма (`SCIENTIFIC_FORM`):** `FORMULA` / `ESTIMATOR`. Статистичний незміщений оцінювач стратифікованої вибірки.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L4: CLASSICAL_NEEDS_CITATION]`. Класична теорія Горвіца — Томпсона [[33]], застосована до задачі обчислення щільності знань $`y_{hi}`$.
- **Поточний статус у книзі (`BOOK_STATUS`):** `[EXPLICIT_COMPLETE]`. Формулу наведено в рядку 1349.
- **Канонічне формулювання:** Для страти $h$ із загальною кількістю секцій $`N_h`$ та вибіркою $`n_h`$ за імовірності включення першого порядку $`\pi_{hi} = n_h / N_h`$ середня щільність формальних знань $`\hat{\mu}_h`$ незміщено оцінюється як:
  ```math
  \hat{\mu}_h = \frac{1}{N_h} \sum_{i=1}^{n_h} \frac{y_{hi}}{\pi_{hi}} = \frac{1}{n_h} \sum_{i=1}^{n_h} y_{hi}
  ```
  Тут $`y_{hi}`$ вимірюється в ознаках/МБ аналізованого тексту. У поточному навчальному прикладі одиниці мають однаковий обсяг усередині страти, вибірка проста випадкова без повернення. Для нерівних секцій потрібна оцінка сум лічильників на відомий обсяг, а середнє їхніх щільностей не є глобальним виходом на МБ.
- **Рекомендація для вставки/оновлення книги:** Закріпити як базовий статистичний оцінювач первинного зондування корпусів.

#### [ID: CH10-S24-03] Формула баєсового згладжування з априорним порогом маси корпусу ($`M_0`$)
- **Розташування в книзі:** Розділ 24, підрозділ 24.1, рядки 1351–1354.
- **Наукова форма (`SCIENTIFIC_FORM`):** `FORMULA` / `REGULARIZER`. Регуляризована баєсова оцінка сукупної щільності корпусу.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L1: PURE_ORIGINAL]`. Авторська формула М. Федчика з априорним порогом стабілізації $`M_0 = 5{,}0\,\text{МБ}`$.
- **Поточний статус у книзі (`BOOK_STATUS`):** `[EXPLICIT_COMPLETE]`. Викладено формулу у рядку 1353.
- **Канонічне формулювання:** Регуляризована оцінка епістемічної щільності корпусу $`\hat{D}_{\mathrm{corpus}}`$ стабілізується зважуванням за масою $M$ відносно априорного порога $`M_0`$:
  ```math
  \hat{D}_{\mathrm{corpus}} = \frac{M}{M + M_0} \sum_{h=1}^{S} W_h \hat{\mu}_h + \frac{M_0}{M + M_0} \mu_0
  ```
  Тут $`W_h = M_h / M`$ є вагою за обсягом аналізованого тексту, $`\mu_0`$ має одиницю ознак/МБ, а $`M_0`$ — МБ. Це авторське згладжування, не виведений баєсівський posterior без додаткової моделі. Воно зміщує результат до очікування. Приклад із двома стратами дає 6,909 ознаки/МБ; значення 5 МБ є навчальним параметром, не виміряною універсальною сталою.
- **Рекомендація для вставки/оновлення книги:** Включити в модуль калібрування профілювальника KAS.

#### [ID: CH10-S24-04] Стандартна похибка з поправкою на скінченність (FPC) та квадрипартитне зонування DensityTier
- **Розташування в книзі:** Розділ 24, підрозділ 24.1, формула 10.49 та її інтерпретація — поточні рядки 1712–1749.
