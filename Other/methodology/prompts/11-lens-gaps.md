# 11. Лінза N: прогалини в наборі вимог

**Мета.** Знайти категорії вимог, які очікуються для такого класу систем, але відсутні або неповні.
**Хто.** Агент із сильною моделлю.
**Вхід.** Усі вимоги, архітектура, код як свідчення фактичної поведінки без вимоги.
**Вихід.** `F-{{PREFIX}}-NNN.md`, журнал `L-{{PREFIX}}.md` з таблицею категорій.

## Промпт

```text
{{COMMON_RULES}}

Задача: лінза N (прогалини) для {{PROJECT}}. Префікс: {{PREFIX}}.
Журнал з таблицею категорій: {{AUDIT}}/lenses/L-{{PREFIX}}.md (створи першим).
Знахідки: {{AUDIT}}/findings/F-{{PREFIX}}-NNN.md. Документи не змінюй.

Чекліст категорій (доповни доменними для {{PROJECT}}):
безпека входу (політика паролів, блокування, MFA, таймаут сесії); обмеження частоти запитів; авторизація на рівні
об'єкта; аудит і його незмінність; персональні дані (мінімізація, видалення, псевдонімізація, строки зберігання);
резервування й відновлення (RPO, RTO, перевірка відновлення); продуктивність (обсяги, час відповіді, пагінація);
помилки (формат, коди, повторні спроби, ідемпотентність); версіонування API і схем; міграції й відкат;
доступність (WCAG); локалізація; офлайн і збої мережі; спостережуваність (логи, метрики, тривоги);
імпорт і експорт (формати, вихід із системи); конкурентний доступ і блокування; конфігурація і секрети.

Для кожної категорії:
1. Пошук у {{DOCS}} і у видобутих RQ: ключові слова категорії (кілька синонімів). Запиши знайдені ID.
2. Пошук у {{CODE}}: чи є поведінка без вимоги (наприклад, ліміт у коді, якого немає в документах).
3. Оцінка: покрито / частково (що бракує) / відсутнє / не застосовно (чому).
4. Для «відсутнє» і суттєвого «частково» — знахідка з типом «прогалина»: чого бракує, ризик, джерело очікування
   (стандарт, клас системи, власна заява документації), форма майбутньої вимоги без вигаданих значень.
Записуй рядок таблиці категорій одразу після кожної категорії.
```

## Перевірка результату

- Кожна категорія має рядок у таблиці, навіть «не застосовно».
- Кожна прогалина пояснює, чому її очікують саме тут.

## Типові помилки

- Загальний перелік «що ще бажано» без прив'язки до класу системи.
- Знахідка «відсутнє», хоча вимога є під іншою назвою.
