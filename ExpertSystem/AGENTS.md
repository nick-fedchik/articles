# Регламент та інструкція для агентів (AGENTS.md) — Монографія «Архітектура доказових експертних систем»

Цей документ визначає інженерні та едиторіальні правила для штучних агентів, які працюють у репозиторії монографії **«Архітектура доказових експертних систем»** (`/home/mfedchyk/book/ExpertSystem`).

---

## 1. Головні інваріанти аудиту та редагування монографії

1. **Обов'язкова атрибуція інтелектуальної власності (Authorial IP Attribution):**
   Усі авторські теорії, моделі, алгоритми, класифікації, метрики доказовості, математичні шлюзи та архітектурні інваріанти повинні бути явно марковані та закріплені за автором («на думку автора», «автором монографії запропоновано...», «авторський емпіричний експеримент...»).
2. **Формат блоків GitHub-Flavored Markdown (VSCode Preview Validated):**
   Кожен авторський блок оформлюється суворо через розмітку:
   - Рядок 1: `> [!NOTE]` (без будь-якого додаткового тексту на цьому ж рядку).
   - Рядок 2: `> **Точна назва авторського внеску**`
   - Рядки 3+: Суворо нумерований список пунктів (`> 1. Пункт...`, `> 2. Пункт...`). Заборонено неструктуровані суцільні параграфи.
   - Завершальний рядок (де доречно): `> *Керування рантаймом / Runtime Governance:* Інженерний інваріант або дія шлюзу за Fail-Closed.`
3. **Інваріант кількісної узгодженості (Exact Count Matching):**
   Будь-яке число у назві блоку («Чотири пласти...», «Вісім антипатернів...», «П'ять висновків...», «Три правила...») зобов'язане точно дорівнювати кількості нумерованих пунктів у тілі блоку (1..4, 1..8, 1..5, 1..3).
4. **Мовна політика: лише український оригінал (Ukrainian-Only, тимчасово):**
   - За вказівкою власника (2026-10-20) усі зміни вносяться **виключно** в український оригінал `chXX-*.md` і `registry/chXX-registry.md`. Англійський (`translations/en/`) і німецький (`translations/de/`) переклади не створюються і не оновлюються, щоб зберегти бюджет моделі.
   - Попередній інваріант тримовної симетрії (ідентична кількість доданих рядків в UKR/EN/DE за `git diff --stat`) **призупинено**. Його відновлюють і синхронізують переклади лише за окремою вказівкою власника.
   - Заборонено пошкодження математики LaTeX (зокрема неприпустимі неперенесені таби чи зламані макроси `\text{...}`).
5. **Поглавний життєвий цикл комітів (Per-Chapter Commit & Push):**
   - Робота ведеться суворо по одній главі за раз.
   - Після валідації формату блоків і кількісної узгодженості агент виконує коміт та пуш лише за прямою вказівкою власника:
     `git add chXX-*.md registry/chXX-registry.md && git commit -m "docs(chXX): add strict itemized authorial NOTE blocks (UK only)" && git push origin main`
6. **Захист інтелектуальної власності (IP Protection & Obfuscation Rule):**
   Будь-які приклади коду, що публікуються або модифікуються, обов'язково проходять процедуру знеособлення та не містять конфіденційних ключів чи комерційних таємниць.
