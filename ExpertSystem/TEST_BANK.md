# Банк тестових завдань (Multiple Choice Questions) для автоматизованого модульного контролю знань

Банк тестових завдань призначений для викладачів та студентів вищих навчальних закладів, які використовують монографію **«Архітектура доказових експертних систем»** як базовий або супровідний підручник у курсах підготовки магістрів та докторів філософії (PhD) за спеціальностями 121, 122, 124 та 126.

Банк містить стандартизовані тестові завдання формату вибору однієї правильної відповіді з чотирьох запропонованих (Single Choice MCQ, A–D) для всіх 40 глав монографії, структуровані за 3 змістовими навчальними модулями згідно з [SYLLABUS.md](SYLLABUS.md).

---

## Структура банку тестів
* **Змістовий модуль 1 (Глави 01–15):** Філософські, математичні та лінгвістичні основи інженерії знань (45 тестових завдань).
* **Змістовий модуль 2 (Глави 16–27):** Архітектура ядер виведення, нульове копіювання, діагностика та синтез доказів безпеки (36 тестових завдань).
* **Змістовий модуль 3 (Глави 28–40):** Нейро-символьні контури, сократівський діалог, піраміда тестування та попперівський аудит (39 тестових завдань).
* **Всього в банку:** **120 тестових завдань** із ключами відповідей та теоретичним обґрунтуванням.

# Змістовий модуль 1. Основи інженерії знань, епістемологія та формалізація (Глави 01–15)

### Глава 01. Вступ до експертних систем та інженерії знань

#### Завдання 1.1
Яка фундаментальна характеристика відрізняє сучасні доказові експертні системи від класичних статистичних моделей машинного навчання?
- [ ] A) Використання більшої кількості навчальних параметрів у шарах нейромережі
- [x] B) Гарантія наявності незмінного ланцюга деривації та прив'язка тверджень до першоджерел
- [ ] C) Повна відмова від детермінованих алгоритмів на користь ймовірнісних матриць
- [ ] D) Здатність генерувати правдоподібні припущення за відсутності вихідних даних
> **Обґрунтування (B):** Доказові експертні системи базуються на інваріанті доказовості (Evidence Grounding), де кожен висновок підтверджується незмінним ланцюгом формальних правил і посилань на першоджерела, унеможливлюючи неконтрольовані галюцинації.

#### Завдання 1.2
Що описує парадокс Фегенбаума (Feigenbaum Bottleneck) в історії штучного інтелекту?
- [ ] A) Обмеження пропускної здатності шини процесора при передачі великих масивів знань
- [x] B) Складність та трудомісткість ручного вилучення знань у експертів-людей для кодування в базу правил
- [ ] C) Неможливість розв'язання задачі комівояжера за поліноміальний час
- [ ] D) Експоненційне зростання енергоспоживання графічних прискорювачів
> **Обґрунтування (B):** «Вузьке місце» Фегенбаума полягає у високих витратах часу та когнітивних труднощах прямої вербалізації неявних евристичних знань фахівців-людей у формальний синтаксис правил.

#### Завдання 1.3
У чому полягає семантичний принцип Fail-Closed у прийнятті критичних рішень?
- [ ] A) Система вимикає живлення апаратного сервера при отриманні невідомого запиту
- [ ] B) Система повертає статистично найбільш імовірний варіант за неповної інформації
- [x] C) За відсутності, неповноти або суперечності фактів система повертає безпечну типізовану відмову
- [ ] D) Система автоматично переходить у режим навчання на помилках під час виконання бойової транзакції
> **Обґрунтування (C):** Принцип Fail-Closed (Unknown = Відмова) гарантує, що система ніколи не бере на себе відповідальність за дію чи висновок, якщо вони не мають строгого доказового обґрунтування в нормативній базі.

### Глава 02. Епістемологія машинного знання: істина, доказовість та нормативність

#### Завдання 2.1
Яка концепція істини покладена в основу доказових експертних систем на відміну від кореспондентської теорії істини?
- [ ] A) Прагматична теорія суб'єктивної корисності
- [x] B) Когерентна та дедуктивно-доказова відповідність замкненій системі нормативних аксіом
- [ ] C) Консенсусна теорія більшості голосів у розподіленій базі даних
- [ ] D) Емпірико-індуктивна апроксимація частотності в навчальній вибірці
> **Обґрунтування (B):** В епістемології машинних знань істинність факту визначається його логічною несуперечливістю (когерентністю) та наявністю виведення з фіксованого корпусу нормативних положень.

#### Завдання 2.2
Що визначає інваріант нульового рівня галюцинацій (Zero Hallucination Rate, ZHR = 1.00)?
- [ ] A) Точність передбачення наступного слова мовною моделлю на рівні 100%
- [ ] B) Відсутність орфографічних помилок у текстових відповідях системи
- [x] C) Абсолютну заборону генерації стверджувальних відповідей за відсутності байтового підтвердження в першоджерелах
- [ ] D) Зниження середньоквадратичної похибки класифікатора до нуля
> **Обґрунтування (C):** Інваріант $ZHR = 1.00$ означає, що частка непідтверджених або домислених висловлювань суворо дорівнює нулю: будь-яке позитивне судження має побайтове обґрунтування.

#### Завдання 2.3
Який статус мають так звані «мовчазні знання» (Tacit Knowledge) за Майклом Полані в нормативних експертних системах?
- [ ] A) Вони автоматично приймаються як фундаментальні аксіоми
- [x] B) Вони вважаються невалідними доти, доки не пройдуть екстерналізацію та документальну формалізацію
- [ ] C) Вони замінюються випадковими числовими вагами
- [ ] D) Вони передаються виключно через квантові обчислення
> **Обґрунтування (B):** Неявне знання («ми знаємо більше, ніж можемо сказати») не може бути джерелом нормативного доказу без попередньої явної фіксації у верифікованих специфікаціях.

### Глава 03. За межами довідково-інформаційних систем: дія проти консультації

Чим експертна система, що ухвалює рішення, принципово відрізняється від пошуково-довідкової системи (Information Retrieval / RAG)?
- [ ] A) Обсягом дискового простору для зберігання документів

- [x] C) Переходом від пасивного надання релевантних текстів до генерації юридично значущого контракту дії з оцінкою наслідків
- [ ] D) Використанням векторних баз даних замість повнотекстового пошуку
> **Обґрунтування (C):** Пошукова система відповідає на запит списком джерел, тоді як експертна система формулює предикат дії, перевіряє безпекові обмеження та несе алгоритмічну відповідальність за результат.

- [x] B) Формалізовану структуру даних, що містить команду, прекондиції, постумови, докази допуску та інваріанти компенсації
- [ ] C) Електронний цифровий підпис системного адміністратора
- [ ] D) Сертифікат відповідності стандарту ISO 9001
> **Обґрунтування (B):** Контракт дії містить строгий опис цільової операції, доказ виконання всіх умов безпеки, часові обмеження (TTL) та компенсуючі транзакції на випадок аварійного переривання.

#### Завдання 3.3

- [ ] A) Вона виконується із затримкою у 500 мілісекунд
- [ ] B) Вона відправляється на повторне голосування користувачеві
- [x] C) Вона безумовно блокується із поверненням статусу відмови (Veto)

> **Обґрунтування (C):** Символьне ядро нормативного допуску (Eligibility) володіє правом абсолютного вето над евристичними рекомендаціями (Relevance).

- [x] B) Друга хвиля страждала від крихкості правил та ручного введення, тоді як Четверта хвиля автоматизує здобуття знань із детермінованим лінтуванням
- [ ] C) Четверта хвиля повністю відмовилася від предикатної логіки
- [ ] D) Друга хвиля базувалася на квантових решітках
> **Обґрунтування (B):** Evidence AI долає крихкість класичних систем завдяки автоматизованому видобуванню знань (KAS), формальним граматикам та неперервній верифікації цілісності.

#### Завдання 5.1

- [ ] A) Швидкість, масштабованість, дешевизна інфраструктури

- [ ] D) Інтерфейс користувача, реляційна база даних, веб-сервер
> **Обґрунтування (B):** Довіра до експертного рішення спирається на триєдність: прив'язку до первинного документа, повну простежуваність логічного виведення та неможливість непомітної модифікації фактів.

#### Завдання 5.3

- [ ] B) Нова редакція ігнорується, доки модель не буде перенавчена повністю

### Глава 06. Прикладна математика експертних систем: логіка, невизначеність та міркування

- [ ] D) Лінійна алгебра кватерніонів
> **Обґрунтування (B):** Деонтична логіка формалізує нормативні акти та стандарти безпеки через взаємопов'язані модальні оператори обов'язку, дозволу та заборони ($F(p) \equiv O(\neg p)$).

#### Завдання 6.2
У чому полягає відмінність між теорією свідчень Демпстера-Шафера та класичною теорією ймовірностей?

- [ ] A) Менша обчислювальна складність компіляції байткоду
- [x] B) Природна підтримка ієрархічного успадкування властивостей, слотів за замовчуванням та процедурних прикріплень (Demons)

## Інструкція для викладачів щодо імпорту банку тестів до СДО Moodle

Для автоматизованого імпорту запитань у тестову систему Moodle рекомендовано використовувати стандартний формат **Aiken**:

```text
Яка ключова парадигма характеризує Четверту хвилю систем штучного інтелекту (Evidence AI)?
A. Використання штучних нейронних мереж прямого поширення (Perceptron)
B. Символьні продукційні правила експертів 1980-х років
C. Глибоке статистичне навчання на терабайтах нерозміченого веб-тексту (LLM)
D. Нейро-символьна синергія з апаратним побайтовим контролем доказів та математичним аудитом
ANSWER: D
```

Або розширений формат **GIFT** (General Import Format Technology) для збереження фідбеку та обґрунтування відповідей:

```text
// [Глава 04] Завдання 4.1
::Ch04_Q01:: Яка ключова парадигма характеризує Четверту хвилю систем штучного інтелекту (Evidence AI)? {
    ~Використання штучних нейронних мереж прямого поширення (Perceptron)
    ~Символьні продукційні правила експертів 1980-х років
    ~Глибоке статистичне навчання на терабайтах нерозміченого веб-тексту (LLM)
    =Нейро-символьна синергія з апаратним побайтовим контролем доказів та математичним аудитом # Четверта хвиля об'єднує перцепцію нейромереж з детермінованою строгістю символьних машин і аудитом.
}
```
