# TASK-ZNA-168.3. Двобічне порівняння та обчислення TE

**Основне завдання:** [TASK-ZNA-168](../TASK-ZNA-168-dialectic-transparency.md), крок 2.
**Статус:** Відкрито
**Тип:** код
**Залежить від:** ZNA-168.1
**Блокує:** ZNA-168.5
**Паралельно з:** ZNA-168.2, ZNA-168.4
**Дозволено змінювати:** модуль порівняння та його модульні тести
**Вимога:** REQ-L3-34-23

## Кроки

1. Реалізувати порівняння двох множин елементів (з тексту й з еталонного підграфа) на структурах за специфікацією ZNA-168.1; вхід — структури, а не текст, тож екстрактор не потрібен.
2. Обчислити `C_dial` (частка еталонних елементів, знайдених у тексті), `H_dial` (частка елементів тексту, що є в підграфі) і `TE = min(C_dial, H_dial)`.
3. Повернути списки: знайдені, пропущені, зайві елементи — для діагностики.
4. Модульні тести на синтетичних парах структур: повний збіг, пропуск, надлишок, хибна сторона, хибний тип атаки, хибна цитата, хибний статус, порожні входи.

## Критерії приймання

- Для повного збігу `TE = 1`; для будь-якого пропуску або надлишку `TE < 1`.
- Результат детермінований; граничні випадки поводяться за специфікацією.

## Не робити

Не використовувати екстрактор у цьому підзавданні; не змінювати формули глави.
