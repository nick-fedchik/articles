# TASK-ZNA-170.4. Час, пам'ять і втрата правильних шляхів за різних лімітів

**Основне завдання:** [TASK-ZNA-170](../TASK-ZNA-170-traversal-budgets.md), кроки 3 (друга частина) і 4.
**Статус:** Відкрито
**Тип:** вимірювання
**Залежить від:** ZNA-170.2 (варіант А), ZNA-170.3
**Блокує:** ZNA-170.5
**Дозволено змінювати:** новий скрипт вимірювання та файли результатів

## Вхідні дані

Рушій із параметрами лімітів; еталонний обхід без відсікань; контрольний набір запитів (створити й версіонувати; якщо вже є — використати).

## Кроки

1. Визначити сітку лімітів (включно з початковими `N_hub = 50`, `deg⁺ ≤ 20` і без обмежень).
2. Для кожної точки виміряти час (повтори, прогрів, медіана й 99-й перцентиль) і пікову пам'ять.
3. Порівняти знайдені шляхи з еталонним обходом; обчислити частку втрачених правильних шляхів із довірчим інтервалом (при нулі втрат — правило з [глави 36, §5.5](../../../../ch36-knowledge-testing-pyramid-and-variational-calibration.md)).
4. Записати платформу (процесор, частота, пам'ять, ОС), версії графа й коду, параметри, команди.

## Критерії приймання

- Для кожної точки сітки є час, пам'ять і втрати шляхів.
- Сирі результати збережено; повторний запуск відтворює їх у межах шуму.

## Не робити

Не вибирати фінальні ліміти й не змінювати контрольний набір після перегляду результатів.
