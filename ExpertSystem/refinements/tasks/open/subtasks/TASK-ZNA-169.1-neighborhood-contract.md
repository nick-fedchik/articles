# TASK-ZNA-169.1. Визначення контракту сусідства 1-WL

**Основне завдання:** [TASK-ZNA-169](../TASK-ZNA-169-wl-tversky-contract.md), кроки 1–2 (рішення і специфікація).
**Статус:** Відкрито
**Тип:** аналіз, специфікація, запит рішення автора
**Залежить від:** —
**Блокує:** ZNA-169.2, ZNA-169.3
**Дозволено змінювати:** новий файл специфікації контракту в кодовій базі (чернетка)
**Пов'язані вимоги:** REQ-L2-31-21, REQ-L3-31-21, REQ-L3-31-22

## Вхідні дані

- [Глава 06, §8.4.2](../../../../ch06-applied-mathematics-for-expert-systems.md): сусідство вхідне й вихідне з позначкою напрямку.
- Код 1-WL: агрегує лише вхідних сусідів із типом ребра.
- [Глава 31](../../../../ch31-syllogistic-reasoning-and-relation-lattices.md): застосування оцінки `S_topo`.

## Кроки

1. Порівняти формально контракт глави та реалізації за вимірами: напрямок, тип ребра, кратність, початкові мітки.
2. Описати два варіанти: (А) код змінюється відповідно до глави (вхідні й вихідні сусіди з позначкою напрямку); (Б) залишається лише вхідне сусідство, а текст глави змінюється з обґрунтуванням.
3. Для кожного варіанта записати наслідки для оцінок (приклади), для коду й тексту.
4. **Рішення автора:** подати варіанти власнику й дочекатися вибору; сам вибір не робити.
5. Після вибору записати точний контракт: облік напрямку, типу ребра, кратності, початкових міток, версія контракту.

## Критерії приймання

- Є специфікація одного контракту з версією й явним обліком усіх чотирьох вимірів.
- Вибір автора зафіксовано з датою.

## Не робити

Не змінювати код і главу; не обирати варіант без автора.
