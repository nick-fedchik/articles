# TASK-TST-008.5. Скрипт обчислення SRR і довірчої межі

**Основне завдання:** [TASK-TST-008](../TASK-TST-008-srr-benchmark.md), крок 4.
**Статус:** Відкрито
**Тип:** код і тести
**Залежить від:** TST-008.1
**Блокує:** TST-008.6
**Паралельно з:** TST-008.2, TST-008.3, TST-008.4 (працює на синтетичних даних)
**Дозволено змінювати:** новий скрипт і його тести в кодовій базі

## Кроки

1. Реалізувати читання результатів за схемою TST-008.1 і обчислення SRR, кількості помилок, `N` (за незалежними кластерами).
2. Для нуля помилок обчислити `p_U = 1 − 0,05^(1/N)`; для ненульових помилок — відповідний біноміальний інтервал (метод вказати в коді й звіті).
3. Модульні тести: `N = 300`, 0 помилок → `p_U ≈ 0,0099`; ненульові помилки не використовують формулу нуля; кластеризація зменшує `N`.
4. Вивід: SRR, `N`, помилки, межа, припущення; фатальна помилка при порожніх або неповних даних.

## Критерії приймання

- Тести проходять, включно з контрольним значенням 0,0099.
- Скрипт не повертає `SRR = 1` без вказання межі.

## Не робити

Не запускати на реальних результатах до заморожування TST-008.3.
