# TASK-ZNA-168.5. Мутаційні тести, блокування тексту та звіт TE

**Основне завдання:** [TASK-ZNA-168](../TASK-ZNA-168-dialectic-transparency.md), кроки 4–5, критерії приймання.
**Статус:** Відкрито
**Тип:** код, тести, звіт
**Залежить від:** ZNA-168.2, ZNA-168.3, ZNA-168.4
**Блокує:** —
**Дозволено змінювати:** модуль інтеграції (перевірка → блокування/шаблон), каталог тестів, звіт; [главу 34, §6.4](../../../../ch34-deterministic-relational-analysis-abduction-and-socratic-dialogue.md) лише з позначкою про наявність протоколу

## Кроки

1. З'єднати екстрактор і порівняння: за `TE < 1` текст блокується, повертається перевірений шаблон із діагностикою.
2. Додати мутаційні тести на всьому наборі: вилучений аргумент, доданий аргумент, хибна сторона, тип атаки, цитата, статус. Кожна мутація має давати `TE < 1` і заміну шаблоном.
3. Запустити на наборі без мутацій: підтвердити, що знайдено всі еталонні елементи; записати кількість зайвих елементів, `C_dial`, `H_dial`, `TE` по кожному диспуту та в середньому.
4. Перевірити детермінованість: повторний запуск на тих самих версіях дає однаковий результат.
5. Підготувати звіт помилок (невдалі диспути з причинами), команду відтворення, опис меж підтримуваного формату.

## Критерії приймання

- Усі критерії основного завдання виконані.
- Помилка екстрактора ніде не маскується успішним результатом (тест на це є).
- У звіті є застереження: проходження скінченного набору не гарантує правильності для довільного тексту.

## Не робити

Не послаблювати перевірку, щоб досягти `TE = 1`; не змінювати набір без нової версії.
