# TASK-TST-009.3. Розмітка двома експертами та узгодженість

**Основне завдання:** [TASK-TST-009](../TASK-TST-009-analogy-calibration.md), крок 2.
**Статус:** Відкрито
**Тип:** розмітка
**Залежить від:** TST-009.2
**Блокує:** TST-009.5
**Дозволено змінювати:** файли розмітки, журнал розбіжностей, протокол (розділ узгодженості)

## Кроки

1. Не менше двох доменних експертів розмічають пари незалежно один від одного.
2. Обчислити узгодженість (κ Коена та відсоток збігів; метод вказати).
3. Розбіжності розв'язати за процедурою протоколу (третій експерт або узгоджене рішення); журнал зберегти.
4. Заморозити версію набору з контрольною сумою; опублікований варіант без конфіденційних даних.

## Критерії приймання

- Для кожної пари є мітки обох експертів і остаточна мітка; узгодженість обчислена й записана.
- Версію набору заморожено.

## Не робити

Не показувати експертам результати 1-WL чи параметри; не змінювати набір після заморожування без нової версії.
