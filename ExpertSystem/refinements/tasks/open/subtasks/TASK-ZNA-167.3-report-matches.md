# TASK-ZNA-167.3. Звіт E_runtime із переліком збігів

**Блокує:** ZNA-167.5
**Паралельно з:** ZNA-167.4 (різні файли: звіт — модуль виводу, тести — каталог тестів)

**Вимога:** REQ-L3-34-22

## Вхідні дані

Результат обчислення з ZNA-167.2.

## Кроки

1. Сформувати машиночитаний (JSON) і текстовий звіт: значення `E_runtime`, чисельник, знаменник, версія коду (коміт), версії/хеші вхідних корпусів `L_dom`.
2. Додати перелік збігів: літерал, правило, файл, рядок.
3. Додати у звіт межі сканування (включені й виключені каталоги) та спосіб обліку повторів.
4. Звіт має бути стабільним: впорядкований вивід без часових міток у змістовних полях.

## Критерії приймання

- Звіт на тестових даних містить усі перелічені поля.
- Є збіги — вони перелічені з розташуванням; немає збігів — перелік порожній явно.
