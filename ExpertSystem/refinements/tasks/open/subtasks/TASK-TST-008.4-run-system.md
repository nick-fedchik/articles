# TASK-TST-008.4. Запуск системи на парах і збереження сирих результатів

**Основне завдання:** [TASK-TST-008](../TASK-TST-008-srr-benchmark.md), крок 3.
**Статус:** Відкрито
**Тип:** запуск вимірювання
**Залежить від:** TST-008.3
**Блокує:** TST-008.6
**Дозволено змінювати:** лише нові файли сирих результатів

## Кроки

1. Зафіксувати версії: набору, бази знань, експертної системи, конфігурації запуску.
2. Для кожної пари запустити обидва запити в однакових умовах і зберегти повні відповіді та вердикти кожного.
3. Не виправляти систему й набір під час запуску; будь-який збій запису — як окремий результат.
4. Зберегти команду відтворення й контрольні суми результатів.

## Критерії приймання

- Для всіх пар є сирі результати обох запитів і версії всіх компонентів.
- Запуск відтворюється командою з опису.

## Не робити

Не оцінювати вердикти вручну для підвищення SRR; оцінювання робить скрипт TST-008.5.
