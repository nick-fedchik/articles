## 1. Мета й залежності

Непорожні проєкції інтервалів не доводять спільної виконуваності відношень. Для x,y у [0,1] одночасні y=x+1 і y=x−1 несумісні. Хеші засвідчують походження цих правил, не спільного свідка.

Передумови: погоджена typed relation schema, SI-перетворення, scope/версії, семантика defeaters і mapping внутрішнього SYNTHESIZED до канонічного вердикту. Promotion із BOUNDED_HYPOTHESIS використовує [контракт допуску CH28](RESEARCH-CH28-dual-contract.md), не прямий bench→fact.

Це основне завдання на загальну логічну достатність і спільний корпус/оракул композиції. [CH25-COMPOSITION-ADMISSION](RESEARCH-CH25-COMPOSITION-ADMISSION.md) використовує ці результати для окремих перевірок походження, застосовності, відкликання та промоції; повторно виконувати однаковий експеримент у двох завданнях не потрібно. Доведення цього піднабору не залежить від завершення передачі provenance-даних CH25.

## 2. Спростовуваний протокол

1. Формально задати композицію через спільні змінні, відношення та умови застосування. Окремо довести необхідність інтервальних checks і достатність запропонованого сильнішого критерію.
2. На малих синтетичних скінченних доменах порівняти interval-only baseline, точний exhaustive oracle та кандидатний solver. Для неперервного піднабору використати явно названу SMT-теорію/сертифікат.
3. Контролі: сумісний ланцюг; наведені суперечливі відношення; різні розмірності; affine unit conversion; різні редакції; scope mismatch; переможний defeater; рівно одна прогалина; дві прогалини; unknown/timeout.
4. Жодного підключення до виконавчих пристроїв. Кандидати з Jaccard/embedding — лише порядок пошуку, не сертифікаційні передумови.

## 3. Targets та критерії

Ціль — theorem/proof або чесне звуження області. Нового порога часу/числа пакетів немає; ресурсні межі **очікують погодження**. Субмікросекундні benchmarks належать [наявному протоколу продуктивності](TASK-TST-010-performance-evidence.md), не цьому доведенню.

**PASS:** формальна soundness-теорема для заявленого піднабору та незалежні контролі. **FAIL:** будь-який false SYNTHESIZED або невизначений перехід. Публікувати мінімальний контрприклад і негативний результат, не підміняти логічну достатність відсотком успішних тестів.

## 4. Артефакти й точні оновлення

Передати schema, proof/сертифікати, generator, версії solver/рушія, всі constraints й witnesses, baseline/output diff та фактичні команди тестів/доведення. Команди мають відтворюватися у власному checkout без секретних пакетів.

Початковий безпечний контроль відтворює несумісність у малому домені; це не загальний proof:

```bash
python3 -c 'domain=[0,1]; witnesses=[(x,y) for x in domain for y in domain if y==x+1 and y==x-1]; assert set(domain)&set(domain); assert not witnesses; print("nonempty interval projections; no joint witness",witnesses)'
```
