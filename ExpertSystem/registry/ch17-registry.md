- **Наукова форма (`SCIENTIFIC_FORM`):** `LAW` / `REGULARITY`. Фізична закономірність деградації пропускної здатності спільних буферних пулів СУБД.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L1: PURE_ORIGINAL]`. Авторське теоретичне обґрунтування М. Федчика меж універсальних баз даних (PostgreSQL з CTE та pgvector) у місійно-критичних навантаженнях.
- **Поточний статус у книзі (`BOOK_STATUS`):** `[EXPLICIT_COMPLETE]`. Розгорнуто у відповіді на парадигму М. Стоунбрейкера «One Size Does Not Fit All».
- **Канонічне формулювання:** Обчислення транзитивного замикання рекурсивними SQL CTE на глибоких графах простежуваності одночасно з векторним пошуком у межах єдиного простору універсальної реляційної СУБД неминуче спричиняє масове витіснення сторінок із буферного кешу (buffer pool churning) та конкуренцію дискового вводу-виводу, що паралізує паралельні транзакції фіксації критичних журналів аудиту; доказова архітектура усуває це явище шляхом повної ізоляції онлайн-читання у незмінні локальні двійкові структури.
- **Рекомендація для вставки/оновлення книги:** Закріпити як «Закон вимивання буферного пулу Федчика».

#### [ID: CH17-S12-05] Архітектурний варіант mmap-баз знань без попередньої повної десеріалізації
- **Розташування в книзі:** Розділ 12, рядки 522–527 (полеміка з Майклом Стоунбрейкером).
- **Наукова форма (`SCIENTIFIC_FORM`):** `ARCHITECTURE` / `DESIGN_OPTION`. Пам'ять-відображуваний доступ без попередньої повної десеріалізації.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L1: AUTHORIAL_PROPOSAL]`. Авторська пропозиція застосувати статичний зліпок знань для зменшення роботи зі збирання структур під час старту; перевагу затримки не виміряно в цій главі.
- **Поточний статус у книзі (`BOOK_STATUS`):** `[EXPLICIT_COMPLETE]`. Перевагу відокремлено від гарантії часу холодного старту.
- **Канонічне формулювання:** `mmap(2)` відображає файл без попередньої повної десеріалізації; сторінки підтягуються під час першого звернення, тому холодний старт залежить від сховища, кешу та робочого набору. Межа 50 мс є вимогою конкретного профілю й потребує вимірювання на цільовій апаратурі.
- **Рекомендація для вставки/оновлення книги:** Не називати mmap нульовим холодним стартом; підтверджувати часовий бюджет окремим випробуванням.

#### [ID: CH17-S12-06] Науковий вердикт глави: детермінований тріадичний базис сертифікованого технологічного стека
