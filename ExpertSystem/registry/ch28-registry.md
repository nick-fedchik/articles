#### [ID: CH28-S01-01] Формальна математична модель структури розширеної відповіді $\mathcal{Y}_{\mathrm{ext}}(q)$
- **Розташування в книзі:** Розділ 1, рядки 23–36; блок `[!NOTE 1]`, рядок 68.
- **Наукова форма (`SCIENTIFIC_FORM`):** `MATH_MODEL` / `METRIC`. Формальна структура вихідних даних дворежимної системи.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L1: PURE_ORIGINAL]`. Авторська математична модель М. Федчика, що задає топологію виходу через впорядковану пару.
- **Поточний статус у книзі (`BOOK_STATUS`):** `[EXPLICIT_COMPLETE]`. Формулу наведено у виділеному блоці math:
  $$\mathcal{Y}_{\mathrm{ext}}(q) = \bigl\langle\,\mathcal{T}_{\mathrm{strict}}(q),\ \mathcal{H}(q)\,\bigr\rangle, \qquad \mathcal{H}(q) = \{h_1, \dots, h_k\}$$
- **Канонічне формулювання:** Вихідний результат дворежимної експертної системи на запит $q$ моделюється строго впорядкованою парою $\mathcal{Y}_{\mathrm{ext}}(q) = \langle\mathcal{T}_{\mathrm{strict}}(q), \mathcal{H}(q)\rangle$, де перший елемент $\mathcal{T}_{\mathrm{strict}}(q)$ є незмінним результатом строгого детермінованого ядра (доведений факт із цитатами або типізована відмова $\mathrm{Refusal}(\rho)$), а другий елемент $\mathcal{H}(q)$ є множиною дорадчих гіпотез, що мають окремий непересічний епістемічний статус.
- **Рекомендація для вставки/оновлення книги:** Зберегти поточний вигляд формули та розшифровки параметрів.

#### [ID: CH28-S01-02] П'ятикомпонентний верифікаційний кортеж дорадчої гіпотези $h_i$

- **Наукова форма (`SCIENTIFIC_FORM`):** `MATH_MODEL` / `METRIC`. Формальний паспорт структури гіпотези.
- **Рівень оригінальності та перевірка на плагіат (`ORIGINALITY_LEVEL`):** `[L1: PURE_ORIGINAL]`. Авторська структура даних М. Федчика, яка унеможливлює існування бездоказових або нефальсифікованих припущень в інженерному середовищі.

- **Рекомендація для вставки/оновлення книги:** Зберегти без змін.
