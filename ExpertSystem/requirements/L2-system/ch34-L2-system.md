## REQ-L2-34-05

- **Вимога:** Експертна система повинна відхиляти кожне судження без першоджерела або з некоректними байтовими межами цитати.
- **Джерело:** [ch34](../../ch34-deterministic-relational-analysis-abduction-and-socratic-dialogue.md), §2.2 «Судження (Judgments / Propositions)».
- **Батьківська вимога:** REQ-L1-34-11.
- **Пов'язана вимога:** REQ-L2-32-10 стосується кандидатів мовної моделі; ця вимога визначає наявність джерела та коректних байтових меж для судження незалежно від способу його отримання.
- **Метод верифікації:** Тест.
- **Пріоритет:** P1 (Основна).
- **Статус:** Проєкт.
- **Перевірка:** Судження без ідентифікованого джерела або з межами за межами файла не допускається, незалежно від того, чи запропонувала його мовна модель.

## REQ-L2-34-10

- **Вимога:** Експертна система повинна класифікувати індуковані правила за порогами `Conf_PCA` і `Supp` (присвоювати `VerifiedCandidate` при `Conf_PCA ≥ 0,90` і `Supp ≥ 10` зі збереженням побайтових цитат опорних фактів, статус `QUALIFIED` із ескалацією людині-експерту при `Conf_PCA ≥ 0,90` і проміжній підтримці `3 ≤ Supp < 10`, статус `QUARANTINE_HYPOTHESIS` при `0,70 ≤ Conf_PCA < 0,90` і `Supp ≥ 3`) та відхиляти всіх кандидатів із `Supp < 3` або `Conf_PCA < 0,70`.
