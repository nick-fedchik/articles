## REQ-L2-18-01

- **Вимога:** Експертна система в закритому автономному профілі розгортання (`Air-Gapped`, обов'язковому для класів ASIL і критичних систем) повинна виконувати запит і формувати доказовий пакет без жодного звернення до зовнішньої мережі.

- **Метод верифікації:** Тест.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L2-18-16

- **Вимога:** Експертна система повинна активувати `Strict Isolation Lock` (блокування USB-накопичувачів, нешифрованих дампів пам'яті, завантаження нових ваг і баз правил), коли верхня оцінка ризику за горизонт $`\overline{P}_{\mathrm{leak}}`$ перевищує параметр профілю `P_max` (у прикладі глави `0,0001`), $`\overline{P}_{\mathrm{leak}}`$ не визначено або `R_exfil ≥ τ_risk_accept`. Якщо система вже працює в профілі *Air-Gapped Sovereign*, вона повинна відхиляти монтаж тому знань типізованою відмовою. *Air-Gapped Sovereign* для систем ASIL є умовою розгортання, а не реакцією на поріг.
- **Джерело:** [ch18](../../ch18-execution-infrastructure.md), §3.2 «Безпечний периметр R&D: Air-Gapped виконання та захист інтелектуальної власності (IP Protection)».
- **Батьківська вимога:** REQ-L1-18-11.
- **Метод верифікації:** Тест.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L2-18-21

- **Вимога:** Коли модель похибки чинна для поточного входу й апаратних умов, експертна система повинна дозволяти пряме числове порівняння лише за запасу до порога, строго більшого від сумарної межі похибки.
- **Джерело:** [ch18](../../ch18-execution-infrastructure.md), §8.3.1 «Запас до порога та чинна межа сумарної похибки».

- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L2-18-22
