# Системні вимоги рівня L2: глава 8

## REQ-L2-08-01

- **Вимога:** Кожна вимога повинна мати п'ять обов'язкових атрибутів: власник, джерело, критерії приймання, пріоритет і статус.
- **Джерело:** [ch08](../../ch08-engineering-artifacts-as-data.md), §4 «Структурна модель вимоги».
- **Батьківська вимога:** REQ-L1-08-01.
- **Метод верифікації:** Інспекція.
- **Статус:** Проєкт.

## REQ-L2-08-02

- **Вимога:** Підтвердження тестом повинно прив'язуватися до хешу конкретної версії вимоги. Будь-яка зміна тексту вимоги анулює її верифікаційний статус.
- **Джерело:** [ch08](../../ch08-engineering-artifacts-as-data.md), §4 «Версійна ізоляція свідчень».
- **Батьківська вимога:** REQ-L1-08-01.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-08-03

- **Вимога:** Коли контрольна точка якості `Q_gate` дорівнює 0, конвеєр повинен блокувати коміт артефакту й формувати діагностичний звіт. Коміт дозволено лише за повноти, тестовості, однозначності і несуперечності вимоги (кожен множник дорівнює 1).
- **Джерело:** [ch08](../../ch08-engineering-artifacts-as-data.md), §5 «Контрольна точка якості».
- **Батьківська вимога:** REQ-L1-08-02.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-08-04

- **Вимога:** Показник `Coverage(R→T)` повинен дорівнювати 1,00. Коли він менший за 1,00, експертна система повинна блокувати випуск і передавати непокриті вимоги в систему обліку дефектів.
- **Джерело:** [ch08](../../ch08-engineering-artifacts-as-data.md), §6 «Наскрізна простежуваність інженерних артефактів як основа системної архітектури».
- **Батьківська вимога:** REQ-L1-08-02.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-08-05

- **Вимога:** Для похідного фрагмента текстового файла експертна система повинна зберігати ідентифікатор версії файла, його хеш і напіввідкритий інтервал первинних байтів, щоб перевірити походження цитати без підміни сирих байтів нормалізованим текстом.
- **Джерело:** [ch08](../../ch08-engineering-artifacts-as-data.md), §9.1 «Простежуваність на рівні байтів: побудова Source Map для вихідних артефактів».
- **Батьківська вимога:** REQ-L1-08-03.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.
- **Перевірка:** Для UTF-8-файла з багатобайтовими символами збережений байтовий зріз відтворює цитату; зміна первинного файла виявляється за хешем.
