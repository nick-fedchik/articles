# Системні вимоги рівня L2: глава 36

**Джерело:** [ch36-knowledge-testing-pyramid-and-variational-calibration.md](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md)

## REQ-L2-36-01

- **Вимога:** Експертна система повинна тестувати кожне правило, предикат і фрейм окремо, без підключення глобальної бази фактів.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §3.1 «Визначення та об'єкт тестування».
- **Батьківська вимога:** REQ-L1-36-01.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-36-02

- **Вимога:** Експертна система повинна відхиляти тест правила як дефектний, якщо правило спрацювало без обов'язкових передумов і зберігати невідомість відсутнього факту.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §3.3 «Пастка вакуумної істинності (The Vacuous Truth Trap)».
- **Батьківська вимога:** REQ-L1-36-02.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-36-03

- **Вимога:** Експертна система повинна при активації перевіреного підривного дефітера зупиняти виведення на цільовому вузлі та анулювати похідні висновки.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §4.2 «Інжекція спростовних дефітерів (Defeater Interruption за AGM)».
- **Батьківська вимога:** REQ-L1-36-03.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.

## REQ-L2-36-04

- **Вимога:** Експертна система повинна вимагати схваленої відповідності онтологічного контексту, коли два атрибути збігаються лише за базовим типом і одиницею.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §4.1 «Багатоходові решітки виведення (Inference Lattices)».
- **Батьківська вимога:** REQ-L1-36-18.
- **Метод верифікації:** Тест.
- **Статус:** Проєкт.
- **Перевірка:** «Таймаут сокета» не передається як «таймаут встановлення з'єднання» лише через однакову одиницю; схвалене правило відповідності для заданого контексту дозволяє передачу.

## REQ-L2-36-05

- **Вимога:** Експертна система повинна блокувати або замінювати пояснення, що містить твердження, відсутні в трасі доведення.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §5.1 «Наскрізне тестування експертної системи».
