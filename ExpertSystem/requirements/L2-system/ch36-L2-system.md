- **Вимога:** Експертна система повинна тестувати кожне правило, предикат і фрейм окремо, без підключення глобальної бази фактів.

## REQ-L2-36-09

Порожні або нечислові вимірювання не дають `PASS`, а гістерезис не зараховується як доказ неперервності релейного виходу.

## REQ-L2-36-11

- **Вимога:** Експертна система повинна розрізняти `ZHR_gate = 1,00`, емпіричну оцінку й сертифікацію ASIL/SIL; за нуля збоїв на незалежній вибірці `N ≥ 30` обчислювати односторонню 95 % верхню межу `p_U = 1 - 0,05^(1/N)`. Для цілі `p_max` мінімальний обсяг визначається як `ceil(ln(0,05)/ln(1-p_max))`; цілі `0,01`, `0,0001`, `0,000001` потребують відповідно 299, 29 956 і 2 995 731 випробування. Політика `d = max(1, floor(log10(N/3)))` не замінює межі: нижня округлюється вниз, верхня вгору, рішення приймаються за неокругленими значеннями.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §5.5 «Метрологія нульових галюцинацій (ZHR)».
- **Батьківська вимога:** REQ-L1-36-09.
- **Метод верифікації:** Аналіз.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L2-36-12

- **Вимога:** Експертна система повинна блокувати публікацію емпіричного показника без `N ≥ 30`, довірчого рівня 95 %, верхньої межі `p_U = 1 - 0,05^(1/N)` за нуля збоїв або з округленням, яке посилює гарантію. Розрядність `d = max(1, floor(log10(N/3)))` є політикою звітування; додаткові розряди дозволені лише як позначені дані для відтворення, не додаткова впевненість. Емпіричний клас не повинен подаватися як сертифікація ASIL/SIL.
- **Джерело:** [ch36](../../ch36-knowledge-testing-pyramid-and-variational-calibration.md), §5.5 «Метрологія нульових галюцинацій (ZHR)».
- **Батьківська вимога:** REQ-L1-36-10.
- **Метод верифікації:** Інспекція.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.
