## REQ-L2-40-05

- **Вимога:** Експертна система повинна дотримуватися конструктивного інваріанта шлюзу `ZHR_gate = 1,00` (із супроводом скінченних вибірок `N ≥ 30` статистичною межею `p_U = 1 - 0,05^(1/N)`): для класу `ASIL-D` випускати вердикт `ACCEPT` виключно на підставі детермінованого формального доведення ядра System 2, для ймовірнісної короборації `Conf ≥ 0,95` за перевіреної незалежності джерел (`A1 ⊥ A2`) у класі `ASIL-D` повертати щонайбільше `QUALIFIED` з ескалацією людині-експерту (дозволяючи автоматичний `ACCEPT` при `Conf ≥ 0,95` лише для некритичних профілів `QM` / `ERL-1..2`), при `0,80 ≤ Conf < 0,95` повертати `QUALIFIED` із обов'язковим переглядом, а при `Conf < 0,80` повертати відмову `REFUSAL`.
- **Джерело:** [ch40](../../ch40-distributed-epistemic-architectures-soa-and-cluster-scaling.md), §5.2.1 «Короборація свідчень (Corroboration)».

- **Пріоритет:** P0 (Критична / Безпекова).
