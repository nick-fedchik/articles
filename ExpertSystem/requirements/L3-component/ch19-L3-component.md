- **Статус:** Проєкт.

## REQ-L3-19-07

- **Вимога:** Нормалізатор зберігає сире зміщення для кожного байта нормалізованого подання, не для символу чи руни; карта має довжину нормалізованих байтів, строго зростає в межах сирого артефакту та разом із версією перетворення й обома хешами ідентифікує відображення напіввідкритого інтервалу на точний сирий зріз.
- **Джерело:** [ch19](../../ch19-from-question-to-evidence.md), §5.2 «Практична реалізація: прив'язка твердження з RFC 768» (функція `normalize`).

- **Метод верифікації:** Тест.
- **Пріоритет:** P1 (Основна).
- **Статус:** Проєкт.

## REQ-L3-19-09

- **Вимога:** Модуль `passage-id` перевіряє схему, межі й носій координат та повторно обчислює SHA-256 канонічного кортежу з ідентифікатора документа, точної ревізії артефакту, версій перетворень, координатного простору, інтервалу й сирих байтів; за нормалізації кортеж також охоплює хеші подання та серіалізованої карти, а кодування має зберігати межі полів.
- **Джерело:** [ch19](../../ch19-from-question-to-evidence.md), §7 «Модель походження: від файлу до атома».

- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L3-19-14

- **Вимога:** Класифікатор повного контракту присвоює `GROUNDED` лише за булевої повноти всіх очікуваних текстових атомів і перевіреного контексту; за часткової прив'язки присвоює `INCOMPLETE_CLAIM` для `0,70 ≤ Comp < 1` або `UNGROUNDED` для `Comp < 0,70`, не встановлюючи причину втрати лише з оцінки. Floating-point значення 1 за неповної булевої перевірки лишається `INCOMPLETE_CLAIM`; навчальні `Comp_text` і `TEXT_ATOMS_BOUND` чотирипольового фрейму не є результатом цього класифікатора.
- **Джерело:** [ch19](../../ch19-from-question-to-evidence.md), §5.1 «Повнота прив'язки та критерії валідності»; §5.2 «Практична реалізація: прив'язка твердження з RFC 768».
- **Батьківська вимога:** REQ-L2-19-10.
- **Метод верифікації:** Тест.
- **Пріоритет:** P1 (Основна).
- **Статус:** Проєкт.
