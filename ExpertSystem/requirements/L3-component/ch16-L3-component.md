## REQ-L3-16-09

- **Вимога:** Для автономного допуску фактів очікувана похибка калібрування (`ECE`) повинна становити `ECE ≤ 0,03`; у проміжній зоні `0,03 < ECE ≤ 0,05` присвоюється статус `QUALIFIED` з обов'язковою ескалацією людині-експерту без автоматичного допуску, а при `ECE > 0,05` скор визнається некаліброваним.
