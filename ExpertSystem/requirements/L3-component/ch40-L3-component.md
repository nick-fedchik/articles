## REQ-L3-40-06

- **Вимога:** Модуль довіри повинен за конструктивного інваріанта `ZHR_gate = 1,00` обчислювати `Conf = 1 - (1 - Cred(A1))·(1 - Cred(A2))` лише за доведеної незалежності ланцюгів походження (`A1 ⊥ A2`): для класу `ASIL-D` повертати `ACCEPT` виключно за детермінованим формальним доведенням ядра System 2, при ймовірнісній короборації `Conf ≥ 0,95` повертати для `ASIL-D` щонайбільше `QUALIFIED` з ескалацією експерту (і `ACCEPT` лише для некритичних профілів `QM` / `ERL-1..2`), при `0,80 ≤ Conf < 0,95` повертати `QUALIFIED` з обов'язковим переглядом, а при `Conf < 0,80` повертати `REFUSAL`.
- **Джерело:** [ch40](../../ch40-distributed-epistemic-architectures-soa-and-cluster-scaling.md), §5.2.1 «Короборація свідчень (Corroboration)».
