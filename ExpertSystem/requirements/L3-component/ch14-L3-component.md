## REQ-L3-14-01

- **Вимога:** Структура `GroundedToken` повинна містити поля `Lexeme`, `ByteStart`, `ByteEnd`, `Line` і `Column`, де `ByteStart` і `ByteEnd` мають тип `uint64`.
- **Джерело:** [ch14](../../ch14-requirements-detection-and-formalization.md), §1.3 «Неподільність деонтичних кванторів, багатобайтові межі Unicode та збереження спанів».
- **Батьківська вимога:** REQ-L2-14-01.
- **Метод верифікації:** Інспекція.
- **Пріоритет:** P1 (Основна).
- **Статус:** Проєкт.

## REQ-L3-14-02

- **Вимога:** Модуль перевірки повинен обчислювати SHA-256 від фрагмента `RawFile[ByteStart:ByteEnd]` і порівнювати результат із хешем у записі бази знань.
- **Джерело:** [ch14](../../ch14-requirements-detection-and-formalization.md), §1.3.1 «Замкнений цикл інженерного розрахунку цілісності спанів».

- **Метод верифікації:** Тест.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.

## REQ-L3-14-03

- **Вимога:** Модуль перевірки повинен переводити правило у стан Fail-Closed, якщо обчислений хеш не збігається з хешем у записі бази знань.
- **Джерело:** [ch14](../../ch14-requirements-detection-and-formalization.md), §1.3.1 «Замкнений цикл інженерного розрахунку цілісності спанів».
- **Батьківська вимога:** REQ-L2-14-02.
- **Пов'язана вимога:** REQ-L3-12-08 вимагає відхилення цитати за невідповідного хешу; ця вимога задає захисний стан для правила.
- **Метод верифікації:** Тест.
- **Пріоритет:** P0 (Критична / Безпекова).
- **Статус:** Проєкт.
- **Перевірка:** Підміна одного байта цитати призводить до невідповідності хешу й захисного стану правила; цитата не використовується як доказ.

## REQ-L3-14-20

- **Вимога:** Маска логітів повинна встановлювати значення `-inf` для кожного токена поза `V_valid`.
- **Джерело:** [ch14](../../ch14-requirements-detection-and-formalization.md), §2.1 «Граматично кероване декодування (GBNF) та нейро-символічний бар'єр валідності».
- **Батьківська вимога:** REQ-L2-14-16.
- **Пов'язана вимога:** REQ-L3-12-39 стосується нульової ймовірності до вибірки; ця вимога уточнює значення маскованих логітів.
- **Метод верифікації:** Тест.
- **Пріоритет:** P1 (Основна).
- **Статус:** Проєкт.
- **Перевірка:** Кожен токен поза `V_valid` має маскований логіт `-inf`; за порожньої `V_valid` декодування не виконує softmax над порожнім набором допустимих токенів.
