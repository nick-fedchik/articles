# Порівняння шлюзу ядра K з базовими рішеннями (H3) та інжекція помилок (H4)

Пакет виконує гіпотези H3 і H4 попередньо зареєстрованого протоколу [`PREREGISTRATION-2026-11-03.md`](../PREREGISTRATION-2026-11-03.md). Він не змінює ядро [`teoskernel`](../teoskernel) і порівнює його з наївним та звичайним інженерним шлюзом допуску на тому самому синтетичному безпековому випадку. Аналіз підготовлено за участі ШІ без фахівця предметної галузі, тому він перевіряє інженерну логіку, а не є галузевою валідацією.

## 1. Навчальний випадок і чотири плечі

LLM-агент пропонує дію `open_admission_valve` — подачу газу в посудину. Дія фізично безпечна, якщо істинний поточний тиск лежить у жорсткому вікні $[0, 8]$ бар, оператор авторизований, є процесний запит, немає блокування обслуговування й інтерлока, а вогневі роботи покриті пройденим газотестом.

| Плече | Інформація | Рішення |
| --- | --- | --- |
| A | скалярна впевненість на факт (noisy-OR надійностей джерел), середина інтервалу як число в барах | плаский ланцюг «спочатку заборони», без свіжості й походження |
| B0 | точкове значення з одиницею, один boolean на факт, журнал походження лише для аудиту | типізовані одиниці, запас похибки 0.3 бар, двостороння свіжість, Horn-замикання, правила за порядком |
| B1 | ті самі метадані, що й у C: інтервали, про/контра, джерела, мітки часу, винятки й пріоритети | той самий стек, написаний з обмежень SC-1…SC-9, з перетворенням одиниць |
| C | ті самі метадані | `teoskernel.Evaluate` над [`CaseSpec`](case.go) |

Варіант B1S (B1 без перетворення одиниць) — розвідувальний аналіз чутливості, його не було в протоколі.

## 2. Відтворення

```sh
go test -race ./teosbaseline
go run ./cmd/teosbaseline -out testdata/teos-baseline           # детерміновані результати
go run ./cmd/teosbaseline -out testdata/teos-baseline -timing   # також timing.csv
```

Сід PCG 20261103; 1000 інжектованих сценаріїв і 250 зіставлених чистих контролів на клас, 1000 сценаріїв класу CLEAN. Файли `results.json`, `results.csv` і `scenarios.csv` детерміновані; `timing.csv` містить мікробенчмарк хоста й не детермінований.

У кожній комірці подано два числа: порушення властивості $P$ / фізично небезпечні дозволи; знаменник кожного класу дорівнює 1000.

## 4. Обмеження

1. Для C критерій $P$ є круговим: ядро допускає дію тоді й лише тоді, коли виконується $P$.
2. Фізична істина залежить від припущень генератора: довірені джерела чесні, а чесний інтервал містить істину. Клас X11 показує, що за порушення цих припущень помиляються всі плечі.
3. Сценарії одного класу не є незалежними реальними випробуваннями, тому межі описують лише синтетичний генератор.
