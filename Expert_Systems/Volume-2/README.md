## Анотація тому

Цей том становить **вибірковий курс «Інженерія знань» (бакалаврат, 3–4 курс; 6 кредитів ЄКТС)** університетського курсу «Експертні Системи» для студентів комп'ютерних наук та програмної інженерії. Матеріал побудовано за ітеративно-інкрементальним принципом із прикладними прикладами у шести наскрізних доменах: **Медицина (`CDSS`), Юриспруденція (`Law`), Військова справа (`Military`: логістика, технічне обслуговування, навчальні СППР штабу), Фінанси (`FinTech / RegTech`), ІТ-інфраструктура (`AIOps / SecOps`) та Промислова інженерія (`CPS`)**.

## 2. Лабораторний практикум Тома 2 (5 обов'язкових робіт)

Кожна лабораторна робота виконується будь-якою мовою програмування загального призначення на вибір студента з використанням автентичних спеціалізованих мов курсу:

1. **Лабораторна робота №2.1:** Офлайн-морфологічний аналізатор (DAWG + WFST) для розв'язання OOV та інженерний граф трасованості EKG з матричним замиканням досяжності (домени: Право, Військові статути, Інженерія; GPU — необов'язково).
2. **Лабораторна робота №2.2:** Аргументаційний рушій ASPIC+ / Dung AF та нормативні схеми з винятками lex specialis (домени: Юриспруденція, Правила ведення бойових дій ROE).
3. **Лабораторна робота №2.3:** Гібридний модуль оцінювання невизначеності: мережі Байєса, правило Демпстера–Шафера та нечіткий висновок Мамдані/TSK (домени: Військова розвідка ISTAR, Медична діагностика).
4. **Лабораторна робота №2.4:** Модельно-орієнтований діагност Рейтера (HS-DAG) та предиктивний оцінювач залишкового ресурсу (STL + RUL) методом Монте-Карло (домени: Інженерія CPS, технічне обслуговування військової техніки; GPU — необов'язково).
5. **Лабораторна робота №2.5:** Автоматизований SMT-верифікатор (Z3) та мутаційний тестувальник бази правил за пірамідою KTP (домени: Медичні протоколи, Банківський комплаєнс, Авіоніка).

## 3. Теми курсових проєктів Тома 2

1. [Інженерія / CPS] Предиктивна експертна система технічної прогностики та оцінювання залишкового корисного ресурсу (RUL) промислового обладнання на базі сигнальної логіки STL, процесів деградації Вінера та конформного виведення ACI.
2. [Юриспруденція / Law] Ізольована корпусно-обмежена експертна система автоматизованого аудиту законодавчих актів і виявлення колізій (lex superior / lex specialis / lex posterior) на базі автоматів DAWG/WFST та аргументаційних рамок ASPIC+.
3. [Військова справа / Military] Оперативно-штабна експертна система оцінювання обстановки (C4ISR) та злиття суперечливих розвідувальних донесень на базі теорії свідчень Демпстера–Шафера, байєсівських мереж та модельно-орієнтованої діагностики.
4. [Медицина / CDSS] Верифікатор клінічних протоколів поліпрагмазії на базі онтологій OWL 2 / SHACL та SMT-солвера Z3 з гарантованим виявленням небезпечних міжлікарських взаємодій.
5. [Фінанси / FinTech] Прецедентна експертна система (CBR) оцінювання кредитних та страхових ризиків із графовим пошуком 1-WL, причинно-наслідковою корекцією парадоксу Сімпсона та калібруванням ECE.
6. [ІТ / AIOps] Модельно-орієнтований діагност каскадних відмов у хмарній мікросервісній архітектурі за методом Рейтера (HS-DAG) з ентропійним плануванням діагностичних зондів.
