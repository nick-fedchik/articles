# Про автора: Микола Федчик

Микола Мартинович Федчик (Mykola Fedchyk, Nick Fedchik) — український інженер і системний архітектор. Понад двадцять років займається розробкою програмного забезпечення, комп’ютерними мережами та вбудованими системами. Працює в Infineon Technologies на посаді Technical Project Manager (Automotive). Серед його професійних інтересів — мікроконтролери AURIX та операційна система реального часу Zephyr.

## Системне програмування

На початку 2000-х Микола розробив для ядра Linux модуль `ebt_vlan` підсистеми ebtables. Модуль дає змогу фільтрувати Ethernet-кадри на мережевому мосту за ідентифікатором VLAN і пріоритетом у тегу IEEE 802.1Q. Також працював із драйвером `irda-usb`.

Для BusyBox портував утиліту `arping`, яка перевіряє доступність вузла в локальній мережі за допомогою ARP-запитів. Для бібліотеки glibc підготував зміни до механізму Name Service Switch: запропонована функція `getethertype` зіставляла назви протоколів Ethernet з їхніми числовими кодами за записами в `/etc/ethertypes`.

Як відрізнити правильну відповідь від збігу, автор описує в [протоколі доказового експерименту](ch36-knowledge-testing-pyramid-and-variational-calibration.md#59-протокол-доказового-експерименту-та-попередня-реєстрація).
