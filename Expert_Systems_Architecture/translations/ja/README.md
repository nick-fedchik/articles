# 証拠に基づくエキスパートシステムのアーキテクチャ

## 概要

本書は、工学文書、要求事項、ソースコード、試験結果を、検証可能な機械推論に利用できる構造化知識へ変換する方法を扱う。全7部・40章で、概念と情報源の形式化、知識モデルと知識獲得、トレーサビリティ、エキスパートシステムのアーキテクチャ、説明、検証、安全性、ニューロシンボリック手法を取り上げる。

特に、証拠の出所と適用範囲、要求事項・規則・設計判断・試験の明示的な関係を重視する。本書は、提案された仮説、形式モデルから導かれた結論、実験で確認された結果を区別し、もっともらしさだけでは証拠にならないことを示す。論理推論、不確実性、因果・時間モデル、説明、制御されたアクション、継続的学習、安全性の論証も扱う。言語モデルは補助ツールとして位置付け、その提案には独立した検証が必要とする。

本書は、複雑な技術環境で意思決定支援システムを設計・評価する学生、技術者、研究者を対象とする。結論の根拠を保持し、その限界を説明し、証拠が不十分な場合には回答を保留できるシステムの構築を目指す。

**キーワード：** エキスパートシステム、知識工学、証拠の出所、トレーサビリティ、形式検証、機能安全、ニューロシンボリックAI。
