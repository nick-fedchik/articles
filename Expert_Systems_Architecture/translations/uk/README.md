# Архітектура доказових експертних систем

## Реферат

Книга розглядає, як перетворювати інженерні документи, вимоги, код і результати випробувань на структуровані знання, придатні для перевірюваного машинного міркування. У семи частинах і сорока главах вона послідовно охоплює формалізацію понять і джерел, моделі знань, здобуття та простежуваність знань, архітектуру експертних систем, пояснення висновків, верифікацію, безпеку й нейро-символьні підходи.

Центральна увага приділяється походженню свідчень, межам їх застосовності та зв'язкам між вимогами, правилами, рішеннями й тестами. Книга розрізняє запропоновану гіпотезу, висновок у формальній моделі та результат експерименту; сама правдоподібність відповіді не вважається доказом. Розглядаються логічне виведення, невизначеність, причинні й часові моделі, пояснення, контрольоване виконання дій, безперервне навчання та аргументація безпеки. Мовні моделі розглядаються як допоміжний засіб, пропозиції якого потребують незалежної перевірки.

Праця призначена для студентів, інженерів і дослідників, які проєктують або оцінюють системи підтримки рішень у складних технічних середовищах. Її мета — показати, як будувати системи, що не лише формують висновки, а й зберігають їхні підстави, пояснюють обмеження та можуть утриматися від відповіді за недостатності даних.

**Ключові слова:** експертні системи, інженерія знань, походження свідчень, простежуваність, формальна верифікація, функціональна безпека, нейро-символьний ШІ.
