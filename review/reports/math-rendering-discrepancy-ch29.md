# Розбіжність перевірки формул CH29

## Висновок

Автор повідомив про два повідомлення GitHub «The following macros are not allowed: operatorname» на сторінці CH29. Отже, попередній локальний `PASS` не встановлював GitHub-сумісності: він підтверджував лише розбір формул MathJax 4.1.3 у локальній конфігурації. Методика й раніше відокремлювала цей результат від S7, але сам валідатор не мав регресії для конкретного спостереженого обмеження.

Офіційна довідка GitHub каже, що математичне відображення використовує MathJax і підтримує широкий набір макросів, але не надає повного списку дозволів або заборон. Повторно відкрити сторінку з тією самою помилкою в цьому пакеті не виконувалося. Тому зафіксовано лише одне авторське спостереження для `operatorname`, не універсальну політику GitHub.

## Виправлення

- У CH29 та реєстрі `\operatorname*{arg\,max}` замінено на `\arg\max` із тим самим аргументом оптимізації. Еквівалентний синтаксис уже використано в інших главах книги.
- У CH19, CH23, реєстрі CH03 та архівному українському звіті `\operatorname{Canon}`, `\operatorname{dist}`, `\operatorname{Retrieve}` і `\operatorname{diag}` замінено на відповідні `\mathrm{...}` форми.
- Англійські, німецькі й польські переклади не змінювалися відповідно до замороження перекладів; вони досі містять старий запис CH29.
- `inspect_render_syntax.mjs` тепер звітує фактичні додавання/вилучення TeX-пакетів, а не не застосований до MathJax список. Self-test рахує контроли, має позитивний приклад `\arg\max` і розділяє локальний MathJax результат від observed-only перевірки `operatorname`.
- B2-19 звужено до зафіксованого спостереження, а не повного GitHub allowlist. Перевірка не називає нуль знайдених входжень підтвердженням відображення.

## Перевірки

- Self-test валідатора пройшов: MathJax локально приймає `\operatorname`, а окремий контроль виявляє його як повідомлену GitHub-відмову. Це навмисно показує межу між рушіями.
- Повний локальний прогін: 17 735 / 17 735 формул MathJax, 320 / 320 Mermaid-блоків, 6 248 локальних посилань пройшли; 49 посилань заморожених перекладів виключено. Observed-only пошук за `operatorname`: 0 входжень у формулах активного українського корпусу.
- П'ять інспекторів і 30 тестів пройшли; точна GitHub-сторінка не перевірялася.

**Залишок:** GitHub-відображення CH29 та черги V-19 не верифіковано. Для перекладів виправлення очікує окремого зняття замороження. Ні локальний MathJax PASS, ні observed-only gate не є GitHub PASS.
