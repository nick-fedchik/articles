# Технічна підготовка українського корпусу

**Дата:** 2026-10-30. **Підстава:** пряме доручення автора запустити технічну підготовку до змістового аналізу. **Обсяг:** 216 файлів — 40 глав, кореневі супутні документи, збірник діалогів, реєстри та прямі вимоги L1/L2/L3. Переклади, історичні беклоги та документація програмного проєкту до прогону не входили.

## 2. Внесені технічні виправлення

1. Захищено два інлайн-вирази змісту й оформлено вісім авторських декларацій CH04 у нумерованих `NOTE`-блоках без зміни вихідних тез.
2. Усунуто три підтверджені TeX-дефекти: regex CH14 винесено зі складного текстового аргументу формули в окремий незмінний шаблон; багатокрапку винесено з текстового режиму; відновлено пошкоджений індекс у реєстрі CH30.
3. Виправлено 426 локальних адрес: 422 механічно з перевіркою цільового файла й якоря та чотири після окремого звірення. До цього попередня regex-перевірка збірника пропускала цитування виду `[[N]](#src-N)`; її результат не був повною перевіркою всіх посилань. Поточний AST-прогін охоплює й цей синтаксис.
4. Усунуто 520 початкових діагностик математичної розмітки: форматними правками, відновленням зіпсованих escape-послідовностей та виправленням хибного спрацьовування інспектора на буквальному роздільнику в коді. Це не 520 незалежних наукових дефектів.
5. У чотирьох навчальних супутніх документах усунуто неприродні програмні й архітектурні кліше відповідно до мовних правил; ключі тестових відповідей і програмні блоки не змінено.
6. Старий код завершення `1` для `git diff --no-index --check` без діагностик виявився індикатором відмінності нового файла від порожнього, а не свідченням whitespace-дефекту. Під час оцінювання перевірки враховувався й фактичний вивід.

## 3. Середовище й контроль засобів

Використано Node.js 22.22.1, Go 1.27.1, MathJax 4.1.3, Mermaid 12.2.0 та jsdom 26.1.0. Сумісність Node-залежностей перевірено через `npm ci --engine-strict --ignore-scripts`; точні залежності й lockfile збережено в [scripts/render-validation](../../scripts/render-validation/package.json). Встановлені пакети, npm-кеш, Go-кеш, витягнуті лістинги, тестові входи й детальні логи залишаються лише в `review/tmp/`.

Офіційні рушії пройшли позитивні й навмисно пошкоджені контроли; невідома TeX-команда, пошкоджена формула й діаграма відхиляються. Окремі регресії перевіряють захищену GitHub-математику, екранований знак валюти, виключення програмного коду та правильні позиції об'єктів. `noundefined`, `autoload` і `require` вимкнено в суворому TeX-профілі, щоб невідомі команди не маскувалися текстовою підстановкою або довільним завантаженням розширень. DOM-адаптер не є запуском браузера.

Перший Go-прогін CH19 виявив відсутній тестовий вхід, а не встановлений дефект алгоритму. Для повтору завантажено офіційний RFC 768: 5896 байтів, SHA-256 `7dc8880e1ecef9c3f9da0db4b876a16e96bfa4f0953cc9d977d414f8f680c2f0`; тестові очікування не змінювалися. Після цього повний повтор усіх 25 виконуваних груп пройшов із `-race`.

Скрипт [inspect_render_syntax.mjs](../../scripts/inspect_render_syntax.mjs) виконує відтворюваний AST-прогін; команди підготовки наведено в [методиці §7.1](../METHODOLOGY.md#71-обовязкові-валідатори-mathjax-і-mermaid). Постійний [технічний знімок](technical-preparation.json) містить хеші входів, інструментів, підсумки перевірок і явні обмеження. Детальні тимчасові діагностики не підміняють постійного підсумку.

## 4. Відкритий залишок

- Адресний залишок із 60 попереджень усунуто в [пакеті узгодження джерел](source-trace-reconciliation.md). Сам факт існування файла, якоря й узгодженої назви розділу не доводить, що джерело повністю підтримує формулювання вимоги; виявлені змістові питання залишаються окремими.
- 10 Go-груп без повного тестового блока та C-фрагмент CH09 не отримують статусу виконуваного приймання. Python перевірено лише на компіляцію; спеціалізовані CLIPS, Prolog, SPARQL та інші декларативні приклади не виконувалися у власних рушіях.
- Браузерна, візуальна й віддалена GitHub-перевірки залишаються в окремій черзі S7; локальні версії MathJax/Mermaid не оголошено версіями GitHub.
- **Виправлення метаданих 2026-10-30:** первісне поле JSON `mathjax_packages` було жорстко заданим списком, не фактичним переліком, переданим у MathJax. Його замінено на конфігураційні дельти (`removed`/`added`); ефективне замикання пакетів і конфігурацію GitHub той знімок не встановлював. Авторське спостереження GitHub-помилки `operatorname` у CH29 зафіксовано окремо; воно не перетворює локальний MathJax PASS на GitHub PASS.
- Змістову несуперечність, наукові доведення, нормативні атрибуції, емпіричні гарантії та новизну цим прогоном не встановлено. Приймання попередніх наукових звітів не відновлюється автоматично.
- Коміт і push не виконувалися.
