# NORM-02 partial result: CH01–09 applicability and profile thresholds

## Scope

Виконано обмежений C4-перегляд доступних уривків і прямих реєстрів/вимог CH01–09. Для CH01–04 локально перевірено заявлені приклади сфери застосування стандартів та відмінність стандарту від авторської політики; для CH06/08 опрацьовано конкретні профільні пороги. Це не є прийманням повного тексту дев'яти глав або S3-наукового рецензування.

## Результат

- **CH01:** У §2 прямо сказано, що ISO 26262, FDA CDS і DO-178C мають різні сфери й статус; для виробу визначають застосовні вимоги. Анотація перелічує ASIL-D/DO-178C як сфери застосування, а не як архітектурний мандат для експертної системи. Додаткових правок не потрібно.
- **CH03:** У прикладі релізного шлюзу MC/DC 100 % явно названо внутрішнім правилом випуску; ISO 26262-6 рекомендує відповідний тип покриття. Межа між рекомендацією й проєктним порогом уже сформульована.
- **CH06:** $`\tau_K=0{,}50`$ більше не представлено як нормативний default для ASIL D. Значення 0,50/0,75 подані як авторські пороги двох профілів; реальне значення задається погодженою політикою. CH06-S07-15/16 синхронізовано, CH06-S03-01 відновлено дослівно з committed версії після виправлення generic patch-hunk.
- **CH08:** $`\tau_{\mathrm{trace}}=0{,}95`$ визначено як авторський параметр прикладу, не стандартну вимогу; за невідомого результату автоматичний запис не відбувається. Умова `Coverage=1.00` ідентифікується як необхідна умова конкретного авторського профілю, не самостійний критерій сертифікації; заголовок і CH08-S06-03 синхронізовано.
- **CH02/04/07/09:** У межах виконаного пошуку/читання не зафіксовано додаткового конкретного C4-протиріччя. Це не є повною перевіркою глав.
